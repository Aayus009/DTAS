DTAS tests in Visual Studio, SSMS, and Postman
==============================================

Complete Pass/Fail here (Status column):
  FYP Diagrams\Testing\DTAS-Test-Run-Guidelines.docx

Case inventory (same IDs):
  FYP Diagrams\Testing\DTAS-Test-Cases-Apps.docx

Order: Unit (VS) -> Integration (SSMS) -> System (SSMS) -> start site -> Interface (Postman) -> Security (Postman)
One case at a time. 21 cases total.


1. UNIT — Visual Studio Test Explorer (NUnit)
   Open:  DigitalTransparencySystem.sln
   App:   Visual Studio

   1. Build > Build Solution (Ctrl+Shift+B). Wait for success.
   2. Test > Test Explorer.
   3. If the list is empty, Run All once to discover tests, then run one method at a time.
   4. Right-click the method, Run. Green = Pass. Type Pass/Fail in Table 2 of the guidelines Word file.

   Run these, one by one:
     UT-01  UT01_AdminRoleIsRecognised
            Expect: Admin true; Faculty and Student false.
     UT-02  UT02_OnlyFacultyAndStaffMayBeEventLead
            Expect: Faculty and Staff true; Student and Admin false.
     UT-03  UT03_OnlyFacultyMayCreateAssignments
            Expect: Faculty true; Staff and Student false.
     UT-04  UT04_AdminIsNotACreateEventRole
            Expect: Admin false; Faculty and Staff true.
     UT-05  UT05_PasswordHasherHashAndVerify
            Expect: hash starts with pbkdf2$; correct password verifies; wrong password fails.


2. INTEGRATION — SQL Server Management Studio
   Server:   AAYUS-ARK009\SQLEXPRESS
   Database: DigitalTransparencyDB
   Folder:   Tests\Sql\

   1. Connect with Windows Authentication.
   2. Click DigitalTransparencyDB in Object Explorer.
   3. File > Open > File, pick one .sql file.
   4. Confirm the database dropdown is DigitalTransparencyDB.
   5. Execute (F5). Read the Messages pane (not Results).
   6. Pass = a PRINT line starting with PASS IT-xx. Type Pass/Fail in Table 3.

   Run these, one file at a time:

4. INTERFACE — Postman
   Do not open the .request.yaml file in the code editor. That is source, not the test runner.

   In Cursor / Postman Local Mode:
     1. Click Upgrade to v3 if the orange banner is showing, then close the YAML tab.
     2. In the Postman sidebar switch from Files to Collections (or Items).
     3. Open DTAS API and Security > Interface > API-01.
     4. You should see GET, the URL, and a Send button — not YAML.
     5. Start the site at https://localhost:44353, click Send, then open Scripts / Tests (post-response). Green = Pass.

   In the Postman desktop app:
     Import Tests\DTAS.postman_collection.json
     Open Interface > API-01 > Send > Tests tab.

     API-01  API-01 ConnectApi.ashx refuses anonymous
     API-02  API-02 TaskProgressApi.ashx refuses anonymous
     API-03  API-03 GlobalSearch.ashx refuses anonymous
     API-04  API-04 EventsProgressApi.ashx refuses anonymous
     API-05  API-05 TransparencySync.ashx refuses anonymous
